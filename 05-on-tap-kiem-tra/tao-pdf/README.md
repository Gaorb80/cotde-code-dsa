# Tạo lại hai file PDF

Mã nguồn sinh `pdf/co-hong_cheatsheet.pdf` và `pdf/co-hong_day-du.pdf` (HTML + SVG, in ra PDF bằng Chrome headless).

```
python build.py   # cheatsheet
python full.py    # bản đầy đủ
```

Cần Python 3 và Google Chrome. Trong `build.py`, đổi `OUT` (thư mục xuất) và `CHROME` (đường dẫn Chrome) cho đúng máy của bạn.
